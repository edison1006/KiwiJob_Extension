# Security policy

## Reporting a vulnerability

Please do not disclose credentials, CV contents, access tokens, private user data, or exploitable details in a public issue.

Use GitHub's **Report a vulnerability** option in the Security tab of this repository to open a private security advisory. Include the affected component, reproduction steps, impact, and any suggested mitigation. Allow the maintainers reasonable time to investigate and publish a fix before public disclosure.

Ordinary bugs and feature requests can use the public issue tracker.

## Supported version

Security fixes are applied to the current production release and the latest commit on the default branch. Older unpacked extension builds and self-hosted deployments must upgrade to receive fixes.
